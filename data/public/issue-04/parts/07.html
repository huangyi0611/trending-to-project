它能做什么

  • 镜头库：124 张「镜头配方卡」、150 个镜头，分开场、运镜、转场、文字、界面入场、数据、收尾等 10 类，在线 Gallery 能预览、复制镜头名。
  • 全流程：截取真实页面 → 定视觉方向 → 分镜 → Remotion 动画 → 卡点和音效 → 逐帧检查 → 输出 1920×1080 的 MP4。
  • 出片后打开一个类似剪映的浏览器编辑器（Motion Workbench），能改文案、颜色、剪辑、换镜头再导出。
  • 可以导出剪映草稿：镜头、字幕、音效、背景音乐分轨，在剪映里接着剪（README 写明在 macOS 剪映专业版 11.2 上验证过）。

最突出的点

不会剪视频，也能让 AI 照着「镜头配方」做宣传片

它把剪辑师的手艺拆成了 124 张配方卡：每个镜头怎么动、配什么节奏都写清楚，AI 照着配方拼片子。导出剪映草稿对中文创作者特别友好：AI 出初稿，人在剪映里精修。

适合谁用

要给产品、开源项目或自己的小红书账号做宣传视频的独立开发者和内容创作者。

缺点与应对

  1. 缺点1：环境要求不低，国内下载可能卡住。要 Node.js 和 npm、ffmpeg；卡点分析要 uv；截页面要 puppeteer。Remotion 第一次渲染要下载自带的无头 Chrome，国内网络可能下不来。 应对：优先在 macOS 上用（作者主要在 macOS 测试）；下载卡住时按 README 的说明手动指定浏览器路径；GitHub 慢就从国内镜像 AtomGit 克隆。
  2. 缺点2：Remotion 的许可要看清楚。个人、3 人以内的营利公司、非营利组织可以免费用，商用也行；更大的营利公司要买公司授权。 应对：个人账号做宣传片一般在免费范围内；团队变大前，先查 remotion.dev 上的授权条款。
  3. 缺点3：个人维护，风格比较固定。镜头库是作者调出来的，偏「科技产品发布会」风格；剪映导出的 Windows 版还没测试。 应对：先用 Ink Press 模板跑通一条，再按需要挑镜头；最后的精修放到剪映里做。
技术含金量

价值在于把审美变成能复用的配方。每张镜头卡写清动效、节奏和适用场景，再配一份能运行的 Remotion 代码。AI 从库里挑选、组合、调参数，结果稳定，也改得动。思路和设计系统一样：先攒零件，再拼成品。

逐帧检查是另一个亮点：渲染完用 ffmpeg 抽帧，按视觉检查标准自查一遍，才交给人。AI 产出先自检再交付，这条规矩放到任何内容生成上都适用。

技术关联

① 热门技术取舍：第一期的 hyperframes 是「写 HTML 出视频」的通用底座；第二期的 OpenMontage 偏全流程视频制作；video-shotcraft 专做产品宣传片，带现成镜头库和剪映导出。只想做产品介绍短片，选它最快；要做讲解类的口播视频，看作者的姊妹项目 video-talkcraft。视频工具别同时装好几个，先选一个跑通。
